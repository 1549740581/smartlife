# 项目概览

## 1. 项目名称

Smart Life / 小区生活助手

## 2. 项目目标

构建一个面向小区住户和管理员的轻量化信息服务系统，首期聚焦租赁信息流转：

- 访客可以直接浏览已审核通过的信息
- 小程序底部提供“生活广场 / 个人中心”两个一级入口
- 住户可以发布房屋、车位或闲置物品信息
- 住户可以在个人中心查看发布状态并进入“我要发布”
- 指定审核员用户可以进入后台审核信息

## 3. 核心用户

- 访客：浏览已审核通过的信息
- 普通住户：发布和查看自己的信息
- 审核员：审核和管理平台内容
- 项目维护者：持续迭代后端、小程序和后台能力

## 4. 当前仓库现状

- 后端为 Maven 多模块工程，当前以骨架和配置为主
- 微信小程序已具备访客浏览、模拟登录、发布、详情、个人中心和审核工作台基础能力
- `requirement/` 目录存在，但尚未形成结构化需求文档
- 项目适合从“先定规范，再逐步生成实现”的方式推进

## 5. 产品边界

### 首期聚焦

- 访客态浏览
- 用户登录/注册
- 房屋出租信息发布
- 车位出租信息发布
- 闲置物品信息发布
- 小程序双 Tab 导航
- 信息审核流转
- 信息浏览和联系方式展示

### 暂不纳入首期

- 在线支付
- 即时聊天
- 多小区隔离运营
- 推荐算法
- 复杂 BI 报表

## 6. 成功标准

以下指标作为首期参考目标，后续可以补实际数值：

- 用户可以在 3 分钟内完成首次发布
- 用户进入小程序后能在 1 次点击内切换到“生活广场”或“个人中心”
- 审核员可以在单页完成审核操作
- 核心租赁流程具备完整状态流转和审计字段
- 关键接口具备统一错误处理和基础测试覆盖
