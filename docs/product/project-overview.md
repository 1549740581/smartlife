# 项目概览

## 1. 项目名称

Smart Life / 小区生活助手

## 2. 项目目标

构建一个面向小区住户和管理员的轻量化信息服务系统，首期聚焦租赁信息流转：

- 住户可以发布房屋或车位出租信息
- 住户可以浏览已审核通过的信息并联系发布者
- 管理员可以审核、驳回、下架信息

## 3. 核心用户

- 普通住户：发布和查看租赁信息
- 管理员：审核和管理平台内容
- 项目维护者：持续迭代后端、小程序和后台能力

## 4. 当前仓库现状

- 后端为 Maven 多模块工程，当前以骨架和配置为主
- 微信小程序目录已存在，但业务实现尚未完整展开
- `requirement/` 目录存在，但尚未形成结构化需求文档
- 项目适合从“先定规范，再逐步生成实现”的方式推进

## 5. 产品边界

### 首期聚焦

- 用户登录/注册
- 房屋出租信息发布
- 车位出租信息发布
- 信息审核流转
- 信息浏览和联系方式展示

### 暂不纳入首期

- 在线支付
- 即时聊天
- 多小区隔离运营
- 推荐算法
- 复杂 BI 报表

## 6. 成功标准

以下指标作为首期参考目标，后续可以补实际数值：

- 用户可以在 3 分钟内完成首次发布
- 管理员可以在单页完成审核操作
- 核心租赁流程具备完整状态流转和审计字段
- 关键接口具备统一错误处理和基础测试覆盖
