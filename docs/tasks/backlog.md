# 任务池

本文件用于将需求拆成 AI 或开发者可直接执行的任务单元。每个任务都应具备输入、输出和完成定义。

## 任务模板

```md
## TASK-XXX 任务名称

### 背景

### 输入

### 输出

### 验收标准
- [ ] ...
- [ ] ...

### 影响范围

### 备注
```

## 当前任务池

## TASK-001 建立项目正式文档体系

### 背景

当前仓库仅有 README 和零散 requirement 文件，缺少正式需求、架构和工程规范文档。

### 输入

- 现有 README
- 当前 Maven 模块结构

### 输出

- `AGENTS.md`
- `docs/` 目录及核心文档

### 验收标准

- [x] 有统一文档入口
- [x] 有产品、架构、工程、任务四类文档
- [x] 有 AI 工作约束说明

### 影响范围

- 仓库根目录
- `docs/`
