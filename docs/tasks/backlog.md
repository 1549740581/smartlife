# 任务池

本文件用于将需求拆成 AI 或开发者可直接执行的任务单元。每个任务都应具备输入、输出和完成定义。

## 任务模板

```md
## TASK-XXX 任务名称

### 背景

### 输入

### 输出

### 验收标准
- [ ] ...
- [ ] ...

### 影响范围

### 备注
```
