# 开发计划

## 目标

基于当前已落地仓库，继续维护和扩展首期 MVP：

- 访客浏览
- 用户登录
- 房屋/车位/闲置物品信息发布
- 公开列表浏览
- 我的发布查询
- 审核员入口控制
- 管理员登录
- 审核通过 / 拒绝 / 下架
- 最小可用微信小程序前端
- 地址表驱动的发布与搜索
- 基础单元测试和接口测试

## Phase 1: 后端基础可运行

状态：已完成

### 范围

- 完成统一启动模块
- 补齐基础实体、仓储、服务
- 建立数据库迁移脚本
- 提供健康检查接口

### 交付物

- `app-starter` 可启动
- `User`、`Admin`、`RentalInfo`、`ReviewRecord` 实体
- Liquibase 初始化脚本

### 验收标准

- 本地启动时可以加载 Spring 上下文
- 健康检查接口可访问
- 数据库结构由 Liquibase 初始化

## Phase 2: 用户侧 API

状态：已完成

### 范围

- 访客态浏览与身份切换
- 微信模拟登录
- 用户基础查询接口
- 租赁信息发布
- 公开列表与我的发布
- 地址树接口与地址校验
- 关键词和地址筛选

### 验收标准

- 未登录默认以访客身份浏览公开列表
- 发布默认状态为 `PENDING`
- 公开列表只返回 `APPROVED`
- 用户能查看自己的全部发布状态

## Phase 3: 管理侧 API

状态：已完成

### 范围

- 审核员用户可见的后台审核入口
- 管理员登录
- 管理员退出
- 待审核列表
- 审核通过 / 拒绝
- 强制下架

### 验收标准

- 普通用户不展示后台审核入口
- 拒绝必须带原因
- 非法状态流转被拦截
- 管理接口要求管理员令牌

## Phase 4: 微信小程序 MVP

状态：已完成

### 范围

- 登录页
- 首页列表
- 发布页
- 我的发布页
- 管理审核页
- 底部双 Tab 导航
- 个人中心入口整合
- 发布页前端校验与提交反馈
- 发布页和搜索页地址多级联动

### 验收标准

- 能完成“访客浏览 -> 登录 -> 发布 -> 审核 -> 浏览”的主流程
- 所有页面通过统一 API 模块调用后端
- 访客默认进入生活广场
- 个人中心固定承载“我要发布”和我的发布记录
- 发布成功后能回到个人中心查看状态

## Phase 5: 测试与回归

状态：已完成

### 范围

- Service 层测试
- Controller 层测试
- 关键状态流转回归
- Testcontainers 启动 MySQL / Redis

### 验收标准

- 用户发布、公开列表、审核流转均有测试覆盖
- Maven 测试通过

## Phase 6: 本地运行与联调

状态：已完成

### 范围

- 容器化 MySQL / Redis 本地依赖
- 本地 profile
- demo / seed 数据
- 启动与联调文档
- 模拟登录说明与示例账号说明
- Redis 持久化管理员会话
- Liquibase baseline 初始化

### 验收标准

- `docker compose up -d` 可启动依赖
- `app-starter` 可通过 `local` profile 启动
- 本地数据库包含可直接联调的演示账号和信息数据
- 小程序和后端有明确联调入口
- README 中有清晰的本地联调路径和模拟登录说明

## 本次实现策略

后续迭代建议按以下顺序推进：

1. 多城市和多小区地址维护
2. 地址管理后台或人工录入流程
3. 更完整的小程序搜索体验和空态优化
4. 审核角色配置化和真实微信登录接入
