# 测试策略

## 1. 测试目标

保证首期核心流程“登录 / 发布 / 审核 / 展示”具备基本可回归性。

## 2. 测试层次

### 单元测试

范围：

- Service 层业务规则
- 状态流转校验
- DTO 转换逻辑

### 集成测试

范围：

- Controller 到数据库的完整链路
- JPA 映射和查询行为
- 权限与鉴权关键流程

### 端到端验证

范围：

- 小程序关键页面联调
- 管理端审核主流程

## 3. 首期最低要求

- 租赁信息状态流转必须有测试
- 审核拒绝原因校验必须有测试
- 公开列表只返回 `APPROVED` 数据必须有测试

## 4. 工具约定

- Java 测试默认使用 JUnit 5
- 数据库相关测试优先使用 Testcontainers
- Kotlin 测试工具只在测试层使用

## 5. 测试数据原则

- 每个测试独立构造数据
- 不依赖共享顺序
- 避免将大量业务常量硬编码在多个测试文件中
